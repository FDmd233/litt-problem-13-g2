# Revised $G_2$ manuscript — proof correction (21 October 2026)

This release supersedes `v2.0.0` as the **current version of the proposed $G_2$ realization** for [Litt Problem #13](https://www.problemsilike.com/13). Previous releases remain available unchanged.

## Mathematical statement in the manuscript

The construction uses an elliptic curve and a shifted cyclic triple cover:

```math
E:\ y^2=x^3+Ax+B,\qquad C:\ w^3=y-c.
```

For allowed smooth parameters, the manuscript proposes a polarized Prym threefold with an integral theta surface $X_b$ and the convolution Tannaka pair

```math
\bigl(G(\operatorname{IC}_{X_b}),\omega(\operatorname{IC}_{X_b})\bigr)
 \cong (G_2,V_7).
```
